# 设计决策

这些决策约束项目实现与维护；字段和操作细节分别见 [架构](design.md)及主题文档。

| ID | 决策 | 理由与代价 |
| --- | --- | --- |
| D-01 | 只读固定上游、已知AST形状适配器、独立Webpack构建 | 避免修改上游；承担版本适配成本，未知模式失败 |
| D-02 | 站点功能包表示注册意图，底层动作为capability | 功能图与代码图分离，引用能力不自动注册提供者站点 |
| D-03 | workspace/profile/manifest使用JSON，扩展使用受信ESM | 配置解析不执行用户代码；复杂回调留在扩展实现 |
| D-04 | 每方案单父继承，选择差量，settings顶层替换，overrides数组替换 | 合并和provenance可解释，避免多父和深合并优先级歧义 |
| D-05 | minimal保留宿主默认映射，不加载上游global/unmaps/theme | 当前支持范围可控；更多base需单独适配，schema预留不代表实现 |
| D-06 | 清单声明注册，浏览器工厂返回回调，完整清单预检后统一注册 | 静态冲突不需执行来源；清单/实现不符时初始化失败 |
| D-07 | 自定义冲突报错，override使用具体贡献ID；前缀仅警告 | 不用加载顺序隐式解决自定义冲突；作者承担前缀遮蔽选择 |
| D-08 | 分方案不可变build与原子current，build-all允许部分成功 | 失败保持旧指针；不承诺跨方案全局事务或自动回滚 |
| D-09 | 固定SHA/内容锁与工具链lock，构建不下载来源 | 输入更新显式；复现还需统一Node精确版本与builder实现 |
| D-10 | 创建/更新两个项目SKILL引用公开契约并调用实际CLI | 维护用户意图和非目标配置，不擅自刷新锁或安装浏览器 |
| D-11 | 生成util副本添加严格形状的MV3可选storage存在性检查 | 防止无关初始化阻断功能，保留上游只读，不增加存储能力 |
